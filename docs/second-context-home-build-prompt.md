## 2. 접근성 기준
- 제목 순서: h1은 Hero 하나, 영역마다 h2, 그 안은 h3. 문의 폼 제목·다른 연락 방법은 기존 구조 유지
- 대비: 검정 바탕 본문 #B3B3B3(10.02:1) 이상, 흰 바탕 본문 #4D4D4D(8.45:1). 영상 위 글자는 영상 전 프레임 합성 픽셀로 측정(최저 제목 7.91 · 설명 6.34 @1440px)
- 이미지 alt: 의미 있는 사진·제품 화면은 내용을 설명하는 alt, 같은 내용을 카드 글이 설명하는 맥락 사진은 `alt=""`. "예시 콘셉트" 표시 유지
- 링크·버튼: 누르는 영역 44×44px 이상, 새 탭 링크는 sr-only "(새 탭에서 열림)", 링크는 밑줄 등 색 이외 구분
- 포커스: 3px 외곽선(검정 영역 흰색, 흰 영역 검정), 고정 헤더에 가리지 않음
- 폼: 라벨 항상 보임, 필수는 * + 오류 문구, aria-invalid·aria-describedby, 상태는 role=status, 서버 2xx 뒤에만 성공 표시
- 움직임: 움직이는 요소마다 일시정지, `prefers-reduced-motion`에서 영상·회전·카운트업 정지
- 언어: 한국어 원문을 바꾸면 번역 표에 영어를 추가(빠지면 빌드가 멈춤)
