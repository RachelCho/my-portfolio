# Second Context 기능 정의 (features.md)

- 기준 버전: 2026-11-11, 커밋 `947f46e` (로컬 = 공개 사이트)
- 이번 검증 환경: 2026-11-11 · macOS 26.6.2 · Google Chrome 157.0.8103.39 헤드리스(DevTools Protocol) · 로컬 서버 `python3 -m http.server` · 폭 360 / 375 / 768 / 1440px
- 검증 표시: **브라우저 확인(2026-11-11)** = 이번에 실제로 동작시켜 봄 · **브라우저 확인(2026-10-29)** = 이전 기획서 점검 결과(당시 환경: 로컬 헤드리스 Chrome) · **코드 확인** = 코드만 읽음 · **미확인**
- 문의 폼 시험은 Formspree로 가는 요청을 브라우저에서 가로채 실패·성공 응답을 흉내 냈다. 실제 메일은 보내지 않았다
