- 로그인·회원가입·관리자·게시판·스킬 숙련도는 Second Context 사이트에 두지 않는다(B2B 컨설팅 사이트, Services·Work·Approach 중심). 방문자는 정보를 보고 예약·문의만 하고, 콘텐츠는 저장소의 HTML을 직접 고친다
- 수업 활동(짝 재그리기·스케치 갤러리 등)은 사이트 기능이 아니므로 미완료 기능으로 기록하지 않는다
