# Rachel Cho 포트폴리오

복잡한 B2B SaaS의 업무 흐름을 명확한 사용자 경험으로 설계하는 프로덕트 디자이너이자 제품·UX 컨설턴트 Rachel Cho의 포트폴리오입니다.

## 사이트 링크

- 포트폴리오: https://rachelcho.github.io/my-portfolio/
- Second Context: https://rachelcho.github.io/my-portfolio/second-context.html

## 프로젝트 소개

### 포트폴리오
B2B SaaS와 엔터프라이즈 제품을 전문으로 하는 시니어 프로덕트 디자이너 Rachel Cho(조예경)를 소개하고, 디자인 작업물을 보여주는 개인 포트폴리오 사이트입니다.

### Second Context
Rachel Cho가 운영하는 독립 프로덕트 디자인 스튜디오의 컨설팅 사이트입니다. 미국 진출을 준비하거나 미국 사용자 경험을 개선하려는 한국 B2B SaaS 팀처럼, 새로운 시장을 준비하는 팀을 위해 제품 UX 진단과 설계를 제공합니다.

- 서비스: Product UX Review, Market Context Session, Design Partnership
- 페이지: Why Us · Services · Work · Approach · Contact
- 언어: 한국어 기본, 영어 페이지 제공

## 만든 방법

Claude Code로 제작하고 GitHub Pages로 배포했습니다.

## 디자인 스타일

포트폴리오는 **스타일 C — 카드형(벤토 그리드)** 기준을 따릅니다.

- Pretendard 단일 폰트, 콘텐츠 폭 1360px, 12컬럼 그리드
- 모든 콘텐츠 블록을 흰색 카드(모서리 22px, 옅은 그림자)로 감쌈
- 섹션 제목 위에 알약 라벨(`PORTFOLIO`, `ABOUT` 등)을 붙임
- 별도 문의 폼 없이, 모든 페이지 푸터에 이메일과 LinkedIn 링크를 둠

자세한 기준은 [design-style.md](design-style.md)를 참고하세요.
